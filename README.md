## What is this?

Latent Carnival is an exploration of generative latent spaces as spectacle. Think of it as a midway of neural curiosities: interpolations that shouldn't work but do, embeddings that cluster in ways that feel like fate, and the beautiful grotesqueries that emerge when you walk the manifold.
